# 🗳️ Ballot Box - College Election System

A secure and web-based College Election System developed to digitize and simplify student elections. The platform enables secure voter registration, tutor verification, candidate nomination, online voting, automated vote counting, and real-time election monitoring. It improves transparency, accessibility, and efficiency while eliminating the limitations of traditional paper-based elections.

---

## 📌 Features

### 👨‍🎓 Student Module
- Student voter registration
- Candidate registration
- Email verification
- Unique Voter ID and Password generation
- Login using assigned credentials
- Forgot Password via email
- Registration status tracking
- Secure online voting
- One vote per position
- Election notifications
- View published results

### 👨‍🏫 Tutor Module
- Secure tutor login
- Verify voter registration requests
- Approve or reject student registrations
- Students receive login credentials after approval
- Manage voters of assigned batch only

### 👨‍💼 Admin Module
- Manage tutors
- Manage candidates
- Manage voters
- Candidate approval/rejection
- Election scheduling
- Position management
- Notification management
- Live election monitoring
- Automated vote counting
- Publish election results
- Grievance management

---

## 🔄 System Workflow

```text
Student Registration
        │
        ▼
Tutor Verification
        │
        ▼
Unique Voter ID & Password sent via Email
        │
        ▼
Student Login
        │
        ▼
Cast Vote
        │
        ▼
Real-Time Vote Counting
        │
        ▼
Admin Publishes Results
```
